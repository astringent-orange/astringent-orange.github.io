10_Jetson Orin NX刷机Ubuntu 20.04

前言

买来的jetson电脑默认系统版本为ubuntu 22.04，需要配置为ros noetic需要的20.4来适配无人机算法环境。大部分内容都可以参考，本文仅对其中一些内容进行补充

前期准备

主机准备

需要准备一台有图形界面的ubuntu电脑以下载官方刷机软件Nividia SDK Manager，虚拟机或者实机都可以。注意到软件官网虽然也提供了windows版本的软件，但是windows版本现在仅适用于Jetson AGX系列，不适用于Orin系列。

下载刷机软件

在官网页面下载软件，正常情况都是选择linux下的x86_64选项

下载完成后，进入到下载目录运行

如果能正常显示则表示安装成功，可使用图形界面或者终端运行sdkmanager打开软件。

注册/登录SDK Manager

注意首次运行时需要通过 NVIDIA Developer 账号登录。没有账号时，需要先在 NVIDIA Developer 网站注册。SDK Manager 会调用浏览器完成登录认证。

进行刷机

Jetson进入恢复模式

图片参考参考文献，使用杜邦线将REC引脚与对应GND引脚短接进入恢复模式，然后上电开机，将jetson使用数据线连接到之前下载sdk manager的主机上。值得注意的是，在恢复模式下jetson的风扇应该是不会运行的，如果风扇在转则说明退出恢复模式了。

SDK Manager配置

在jetson用数据线连接上主机后，在主机上打开sdk manager，理论上应该有如下界面STEP 1。其中target hardware应该能检测到要安装的电脑，主要取消勾选host machine。而关于SDK VERSION选项实际上代表了系统的版本，JetPack的版本与ubuntu的版本是一一对应的，其中jetpack 5.x对应ubuntu20.04，jetpack 6.x对应ubuntu22.04，jetpack 7.x对应ubuntu24.04。这里由于我们需要ubuntu 20.04所以选择jetpack 5.1.6。

其中关于deepstream的部分通常可以不勾选，后续也可以单独安装。

接下来在STEP 2与STEP 3中可以继续参考参考文献。需要额外说明的是，安装时会先安装ubuntu系统，然后再安装各依赖包。而安装依赖包时，已经可以不用恢复模式了（可能此时jetson的风扇已经在转了）。而在安装sdk之前，推荐先进入系统中安装一些基础系统包，否则sdk可能安装失败。

推荐操作为先长按jetson电源键进行关机（不用拔掉与主机的连接线），然后拔掉REC引脚的短接线，然后将jetson外接显示器、键盘、鼠标后重新开机。要注意的是，将jetson关机重启对于sdk manager安装过程是无害的，可以将sdk manager保持在install步骤的界面（具体图像参考参考文献），只是会显示无法连接到jetson而已。重启之后可以观察到，sdk manager仍然可以检测到jetson。（如果拔掉了与主机的连接线，再插回去即可）

继续参考参考文献在jetson上连接网络以及使用fishros进行基础环境的安装，并测试ssh是否能正常启用，完成之后回到sdk manager的界面继续操作。在点击install之前，此处与参考文献有一点不同的是，我们之前没有拔掉jetson与主机的连接线，所以connection选项中我们选择用usb。

点击install之后等待安装完成即可。注意，jetson连接的显示器等外设可以保留，以供下文的其他软件安装。

机载软件安装

nomachine

由于架构不同，jetson上需要安装arm64的版本。在官网首页中，不要选择download now而是选择ohter operating system

然后选择最下方的NoMachine Personal Edition for ARM，选择页面中第二项deb版本进行下载，下载完成后进入到下载文件夹运行sudo apt install ./下载的包.deb安装即可。安装完成后通常需要先运行一次nomachine，确认其是开机自启动以及分享屏幕

Miniconda

运行以下指令安装miniconda

注意

Jetson 上 Conda 的创建方式与普通 Ubuntu 基本相同，但由于 Jetson 使用 ARM64 架构且 CUDA 由 JetPack 管理，因此 PyTorch、torchvision 等 GPU 相关库不能直接使用普通 x86 CUDA wheel，需要安装 NVIDIA 提供的 Jetson ARM64 版本，部分库还需要源码编译。

简单来说，由于架构不同jetson上部分GPU相关库不能直接安装，需要安装专有版本或者自行构建，具体情况建议询问ai。推荐是在可以访问ai的电脑上ssh登录到jetson，而不是在jetson上直接访问ai。
